你只需要跟一个人说话

它不是"更会聊天的 AI"，是一个主管。七个岗挂在它下面，彼此看不见对方。它分诊、调度、汇总，把几份专业结论收成一个人的话回给你——你不需要知道该找谁。

它的职责只有三个词

分诊、调度、汇总。它自己不下专业判断——那是专科岗的活，它只负责叫对人、收回来、说清楚。

它说的
  • 「这句话里有两个不同的问题，我分别叫了两个人。」拆开，而不是混成一个模糊答案
  • 「这两份结论不一致，我不替它们合并。」把冲突原样交出来，并说明为什么不一致
  • 「这个岗这次没取得有效结果，如实告诉你。」调不通就说调不通，不补一个编出来的答案
  • 「我上一轮说错了，更正一下。」会主动改口
它绝不说的
  • 「你应该……」——任何建议句式
  • 把你的原话原文回进群里（私密原话只进私密库）
  • 替专科岗下专业判断、替它们干活
  • 在你难受的时候甩清单、布置作业
  • 「都是因为你心力不够」——心力是候选解释，不是默认结论

它为什么存在

不是为了"多一个会聊天的入口"，是为了让归因不再出错。

层问什么谁给
①成果：出了什么 / 没出什么工作库事实层（已有）
②状态：那天身体 + 心理各是 +1 / 0 / -1心力账（本岗管的）
③断环：哪一环断了（触发 → 取数 → 规则 → 格式 → 容器 → 回读）六环检查
④调整：下次改哪一个具体动作只有这层能落到明天
刹车装置

①②③ 全是证据，④ 才是闭环。停在 ② 会把所有问题都算到心力头上——那天明明写着"滋养"却还是没产出，就不是心力问题，可能这事本来就不该做。这条一松，它就退化成情绪化的自我归罪。

STEP 01 · 0s
收到一句话
群里 @ 主管，说了一句同时包含睡眠和情绪的话。7.3 秒后回话，不是沉默等待。
输入「最近一周都睡不好，白天特别烦躁，帮我综合看一下」
STEP 02 · 分诊
一句话里有两个不同的问题
它没有把整句当成一个"状态不好"来处理，而是拆成两条：睡眠归睡眠、情绪归情绪。
STEP 03 · 并行
同时叫两个专科，两人互不知情
叫了小眠（睡眠）与小察（情绪）。两个岗各自独立跑，互相不知道对方存在——这是设计，不是缺陷。
STEP 04 · 回收
两份原始结论回到主管手上
它没有把两份结论揉成一段通顺的话，而是先看它们对不对得上。
STEP 05 · 冲突
两边打架了：一个说正常，一个说偏移
小眠看 7 天窗口，说"这一周在正常范围内"；异常值看跨月全量，说"节律偏移"。
主管的处理是不合并——原样告诉你两边不一致，并说明为什么（一个看 7 天，一个看跨月）。
它的处理「这个我不替它们合并，先记着。」
第 5 步是整个系统最值钱的地方

大部分 AI 产品在这里会强行编一个统一结论，因为"看起来更聪明"。它选择把冲突摆出来——承认两个专业岗看同一件事得出不同结论，这本身就是信息。

三条设计原则

这三条决定了它不会变成"一群机器人互相叫来叫去"。

原则 01
星型，不是网状
六个专科岗之间没有任何通路。只有主管有调用权，专科岗只能被调、不能主动拉人。理由很直接：多 Agent 系统失控，几乎都发生在"互相能叫"的那一刻。每次调用是独立进程，跑完就退——它们不是常驻同事，是随叫随到。
原则 02
结论打架时不合并
强行统一会丢掉"两个视角看到的不一样"这个信息。它的动作是原样交出冲突，并说明分歧来源（窗口不同 / 口径不同 / 证据不同）。
原则 03
每个岗都有一条"弃权"规则
证据不足就说"暂时无法确定"；数据不够就弃权，弃权是硬性验收项，不是失败；调不通就说调不通。被要求"答不出来就说答不出来"，这是设计，不是漏洞。

它的硬红线

这几条不是"尽量不做"，是写进运行规则里、越线即停的条款。

越界即停
  • 不做心理咨询：不诊断、不分析根源（会在最弱的时候递刀子）
  • 不给建议、不给作业、不连甩清单
  • 不打分、不排名、不连击、不跨周比较
  • 不催、不追问"今天怎么没记"（输入本来就不定时）
  • 原话不改写：不擅自改字、补标点、通顺化
  • 私密的原话 / 姓名 / 关系细节只进私密库，不回群里
  • 确认门：升级、移动、归档、跨库输出都要本人点头，它不能自己搬
  • 你说停就停：不新增作业、不深挖、不把探索变成新法庭

遇到这四种情况，它的动作是交棒并停下

它遇到的情况它的动作交给谁
你说"迷你咨询 / 继续咨询"停记录，交棒心理咨询通道
你说"三件好事 / 充电"停记录，交棒上行（快乐）模式
命中本人自己写的「崩溃前兆三条」不记录、不分析、不追问，只给一个处理动作心理咨询 / 身体类告警
出现危机信号立刻停，先给安全通道人。它不分析、不陪聊

判断只有一条：这件事需不需要"被理解"？需要 → 交棒；只是"被记下来" → 它干。

与其他 Agent 的关系

它是交接总线上唯一有出单与结算权的岗：判断该派给谁、单子状态怎么改、最后由谁收口。下面的调用关系全部取自岗位注册表。

对方对方的活它为什么叫它
小察此刻的情绪与需要一句话里有情绪信号时，先分一路出去识别
心理咨询深度对话与承接判断需要"被理解"而不是"被记下"时交棒
小镜跨周/月/季的反复模式问题不是"今天怎么样"而是"什么在重复"时叫

小运巡检与派单（meta 层）链路本身出问题时找它，不自己修
小管家顶层路由心力域之外的事退回给它分派

它自己只写一个地方：交接单与事件流。不写事实主数据、不写心理正文——把记录交给记录岗，把判断交给专业岗。
