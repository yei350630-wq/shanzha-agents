输出长什么样

转录不是终点。原始稿里有两类必然存在的瑕疵，交付前必须处理掉。

问题一 · 回声重复

在停顿和断句边界，同一句话会被相邻重复 2–3 遍，还常常跨段落：

这个造物主就是达尔文的进化论中所说的物竞天择。
这个造物主就是达尔文的进化论中所说的物竞天择。
这个造物主就是达尔文的进化论中所说的物竞天择。

处理原则：只删「紧邻的完全相同句」，不相邻的重复是正常修辞，不能误删。

问题二 · 专名误写

人名、书名、公司名会按发音写错，需按固定词表全局校正：

孟严 → 孟岩　 有志有行 → 有知有行
牵脑智能 → 千脑智能　 新批制 → 新皮质
竖图 → 树突　 提摩西·加尔维 → 蒂莫西·加尔维

交付前复查：错误专名命中数应为 0。

大家好，欢迎来到《来都来了》，我是主播丸子。大家好，我是 Nicole。今天我们录制的这个地方非常的特别。今天我跟丸子在广西的一栋漂亮的玻璃房子里面录制。如果是听我们节目的朋友，可以去看一下我们的视频播客。

非常荣幸受到邀请，我们这次来参加护肤品牌的活动。没错，我们今天要聊的话题也非常的适合这个夏天，叫做「养自己」。

  • 手动下载音频文件
  • 找转录工具、调参数

  • 逐句修错字、删重复
  • 手工分段、加标题
  • 粘贴到文档、调格式

现在 · 交给小D（约 10 分钟）

  • 把链接发给它
  • 自动下载音轨（只取音频）
  • 本地 GPU 转录，无需盯守
  • 自动去回声重复 + 专名校对
  • 按停顿自动分段、生成文档
  • 回一个结果，人只需要看

能力边界

一个 Agent 值不值得信，先看它敢说自己做不到什么

它做不了

  • 需要登录的付费内容——会员专享音频、加密课程，取不到源文件。
  • 纯音乐 / 无人声素材——转录出来没有意义。
  • 没授权的外部会议录音——权限不在它手里，需要先由人授权。
  • 保证 100% 准确的专名——语音识别只能给到「大概率正确」。

需要人工介入

  • 专名终审——词表之外的新人名、术语，建议人工过一遍。
  • 超长音频——2 小时以上建议分段处理，避免单次任务过长。
  • 权限授予失败——涉及第三方平台授权时，需要人点一下。
  • 重要内容校对——用于对外发布前，仍建议抽检。

怎么用

三步，没有学习成本

找到它

在飞书里找到名为「小D」的机器人，或在对应的工作群里 @ 它一次。

把链接丢过去

直接粘贴链接或发送音频文件。不用说「请帮我转录」——它默认就是这个意思。

等结果

它会先回一句「已开始处理」，跑完再给结果。中间不需要你管。

它由什么组成

全部在本机运行，音频不上传第三方
