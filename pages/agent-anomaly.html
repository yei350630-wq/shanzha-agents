发现「和以前不一样」的地方

它是 Life OS 的生活雷达。每晚读一遍当天的事实，跟你平时的基线比一遍，把偏离了的变化摆到你面前——然后闭嘴。它不判断对错，不解释原因，不替你做决定。

「异常不等于出了问题。睡眠增加、运动减少、情绪波动——这些都可能只是『和以前不一样了』。」

它只说一句话

这个岗位的全部职责，可以压缩成一句原话。判定过程不是它的活——发现变化才是。

它说的
  • 「这个地方和你平时不一样了。」只描述偏离，不给结论
它绝不说的
  • 「你出问题了。」
  • 「你拖延了。」
  • 「你抑郁了。」
  • 「你失败了。」

五条核心原则：宁可少报，不乱报

这五条是它的自检清单。每条都对应一类最容易犯的错。

原则 01
每个异常必须挂基线
必须回答「它相对于什么，异常」。基线按优先级取：近 7 天 → 近 30 天 → 近 90 天 → 长期习惯 → 已定目标 → 连续趋势。挂不上基线，就不判。
原则 02
证据不足就输出「暂无明显异常」
不为了每天有报告而强行制造异常。没东西报是合法输出，而且是大多数晚上的输出。
原则 03
禁止诊断原因
跨域异常只说「多个维度同时变化」，不说「你可能抑郁了」。发现和解释是两件事，它只做第一件。
原则 04
不替用户做决定
建议只到「关注 / 继续观察 / 无需处理」这一层。再往前一步就越权了。
原则 05
禁止误判
单日数据不判、无基线不判、情绪不诊断、工作量下降不判懒惰。

四类变化形态，三级严重度

形态回答「怎么变的」，分级回答「多值得关注」。两个维度独立，最后合成一条卡片。

变化形态

形态怎么认真实例子

分级

A 级

明显异常

多维度同时变化，或长期中断

需要你决定要不要处理。它只负责把它摆到台面上。

B 级

值得观察

单一维度偏离，但在合理波动带内

不下结论。挂几天看看会不会自己回去。

C 级

轻微变化

可能只是正常波动

多数情况下这类直接被丢掉，不进你的消息。

五个检测维度

维度看什么
生活节奏睡眠时长（突增/突减）、入睡与起床时间偏移、活动量与运动（突增/突减/中断）

跨域多个变化同时发生 → 聚合提示，禁止诊断原因

注意它没有说的话
  • 它没有说「你睡太多了」。睡眠增加被明确写进「可能只是和以前不一样」的清单，不是问题
  • 它没有说「你这几天太废了」。数据缺口报成「数据」类异常，而不是「你的行为」异常
  • 它没有把这两条连起来解释。关联变化一栏写的是「待跨域聚合判断」，不是「因为你压力大所以睡多了」

它怎么工作

四步，每晚 22:30 自动跑一遍。判断这一步交给模型，数据抽取和基线计算交给脚本——分工写死在设计里。

STEP 01
取数
采集脚本只读事实索引，把睡眠、运动、情绪、工作量按天归拢。永不抛异常，退出码恒 0，不写任何知识库文件。
STEP 02
算基线
脚本按 7 天 / 30 天 / 90 天窗口算均值与趋势，产出结构化候选，附原始值作为证据。
STEP 03
判与分级
这一步是模型的活：这条到底算不算异常、算几级、怎么跟你说。脚本不做判断，也不写结论。
STEP 04
投递或沉默
有异常 → 按卡片格式投递飞书，每条带基线、偏离、变化%、持续天数、证据。没异常 → 一条不发。
有异常时，每条卡片带说明
现象 / 基线发生了什么，相对什么
偏离 / 变化%数值差了多少，方向是什么
持续天数不是一次性的，还是一直没回
关联变化同时间段还有什么别的在动（不解释因果）
判断 / 证据分级结论 + 可回溯到原始事实的证据行

它的硬红线

这六条是从 SOUL 里抄出来的原话，不是概括。检测结果是派生结果，随时可以重生成。

越界即停
  • 不写进知识库 —— 只读，检测结果是派生结果，可随时重生成
  • 不修改 / 删除任何源文件
  • 不做医疗 / 心理诊断
  • 不自动解释原因、不自动改目标、不自动干预
  • 不 @ 任何人
  • 证据必须能回溯到原始事实 —— 带 id、日期、原值
它也不是这些
  • 不是找错误数据的质检员
  • 不是心理医生，也不是诊断工具
  • 不是替你做决定的人

与其他 Agent 的关系

它在这张网里的位置是「读别人写下的东西，找出里面的变化」，然后把需要处理的交出去。它自己不下场。
